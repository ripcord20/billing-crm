ZTE SSH 1.1.0

APK konsol SSH / Telnet untuk OLT ZTE C300 / C320. Bukan lewat server Fiberix — HP harus satu Wi-Fi atau VPN dengan OLT. Siap unggah Play Store (API 36).

Unduh APK Unduh ZIP (jika Chrome memblokir APK)

Kebijakan privasi

Kalau Chrome bilang file berbahaya / tidak umum, pilih Unduh anyway atau pakai tombol ZIP. Lalu buka file ZIP, tap ZTE-SSH.apk, izinkan pasang dari sumber tidak dikenal.

  1. Install APK.
  2. Isi IP OLT, user, password. C320 sering Telnet port 23.
  3. Hubungkan. Salin / Tempel siap dipakai di terminal.
